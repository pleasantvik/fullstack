# Posts

Drafts for LinkedIn and X, written at the end of each increment so progress can
be shared without stopping to write from scratch.

## Convention

- **One file per post.** The filename is the post title, kebab-cased.
- Each file holds **both** versions: LinkedIn (longer, paragraphs) and X (a
  thread, each part under 280 characters).
- Every post answers three things: **what I did**, **what I learnt**, **what's
  next**.
- The header records which increment it belongs to and whether it has gone out.
  Change `Status: draft` to `Status: posted <date>` once published — that way an
  unposted backlog is visible at a glance.

Drafts are committed whether or not they are posted. Writing them at the end of
an increment, while the detail is fresh, is the point; posting can happen later.
